# v2.9.4 Bubble Follow-up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Correct v2.9.4 route support, changelog gating, Fill/clear-all bubble behavior, settings-header info action, and unused Material icon cleanup.

**Architecture:** Keep the verified API v2 queue and pricing untouched. Extend the existing bubble state machine with a small Add mode (`fill`/`clear`), a persisted changelog-seen version gate, and a text/icon renderer. Add clear-all quantity handling beside the existing per-item clear logic and keep all dialog accessibility patterns.

**Tech Stack:** Single-file Tampermonkey userscript, jsdom/Vitest, GM storage, Material inline SVG map, CSS.

**Spec:** `docs/superpowers/specs/2026-09-26-v2.9.4-bubble-followup-design.md`

## Global Constraints

- Keep current version exactly `2.9.4`.
- Preserve API v2 batch size 10, cache format/lifetime, 600 ms spacing, v1 fallback, quantity parsing, pricing, and PDA initialization.
- Support only `#/add` and `#/manage` bubble routes; hide the bubble on base/unsupported and Personalize routes.
- Add bubble label is exactly `Fill`; active drag renders the Material `settings` icon.
- After Quick Fill completes, the Add bubble stays accent-colored and renders `close`; tapping it clears currently loaded quantity boxes and returns to `Fill`.
- Changelog key is exactly `changelogSeenVersion`; close by button/Escape/scrim marks the current version seen.
- Settings header badge is a keyboard-accessible `info` action that closes settings and opens the changelog.
- Remove `inventory_2` and unused `more_vert` from the inline map and source asset directory; Clear cache is text-only.
- Do not auto-scroll, publish, tag, or push.

## Review Focus

- Base `bazaar.php#/` never renders or activates the bubble, and unknown routes cannot fall through to Quick Fill.
- Changelog opens only once per version on Add, never on base route, and never stacks with the API-key prompt.
- Clear All affects only quantity controls on currently loaded rows, preserves prices, and cannot trigger network requests.
- Drag state shows the settings icon without firing a tap, and release/cancel restores the route state.
- Post-fill state is accent plus close, not pink plus check, and reset to Fill after clearing.
