# v2.9.4 Material 3 Bubble and Batch Pricing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release the verified API v2 batch-pricing work together with the v2.9.5 circular bubble, official Material 3 iconography, PDA compatibility, documentation, and version metadata for v2.9.4.

**Architecture:** Keep the existing cache-first API v2 queue and v1 fallback unchanged. Replace only the floating control layer with a circular route-aware bubble driven by centralized Material 3 SVG path data; keep the existing modal, observer, and position-storage patterns. Bump all version references only after the UI behavior and documentation are implemented and tested.

**Tech Stack:** Single-file Tampermonkey userscript, browser Pointer Events, MutationObserver, GM storage/XMLHttpRequest, Vitest + jsdom, ESLint, official Material Design SVG assets.

**Spec:** `docs/superpowers/specs/2026-09-25-v2.9.4-material3-bubble-design.md`

## Global Constraints

- Target version is exactly `2.9.4` in userscript metadata, runtime fallback, package metadata, lockfile, README, changelog, settings modal, and BUILD documentation.
- Preserve API v2 batch size `10`, cache format/lifetime, `600` ms network spacing, and v1 fallback exactly.
- Do not auto-scroll, change quantity parsing, change pricing calculations, or add API key-verification calls.
- Use official Material 3/Google Material Design SVG assets under Apache License 2.0; retain source files and attribution in `docs/assets/material-icons/` and documentation.
- Keep icon SVG path data inline in the userscript; no runtime icon font, icon CDN, or external SVG dependency.
- All icons use `currentColor`, a 24×24 viewBox, and the existing pastel color tokens.
- Bubble size is `52×52` px, circular, fixed-position, draggable, keyboard repositionable, and viewport-clamped.
- Long-press threshold is `350` ms; drag threshold is `6` px; Enter/Space activate without keyup double-firing.
- Route behavior is exact: main opens changelog, Add runs Quick Fill, Manage runs Update All, Personalize hides the bubble.
- Do not unconditionally focus the API-key input when opening dialogs.
- Do not release or push until the final branch review is clean and local verification passes.

## Review Focus

- Route changes between main, Add Items, Manage, and Personalize must update or hide the bubble without duplicate controls.
- A drag must cancel long-press and must not trigger a tap; a long-press must not trigger a route action.
- Add Items completion state must reflect all currently visible positive prices and must not inspect unloaded rows or auto-scroll.
- Material icon mappings must use the correct semantic path and inherit `currentColor`; no old custom icon may remain in the mapped UI paths.
- Version references must be consistently `2.9.4`, while the API v2 queue and v1 fallback remain behaviorally unchanged.
