# Design: v2.9.4 Material 3 Bubble and Batch Pricing Release

**Date**: 2026-09-25
**Status**: Approved scope, pending implementation
**Target version**: 2.9.4
**Branch**: `feature/api-v2-batch-pricing`

## Objective

Release the verified API v2 batch-pricing improvements together with the useful
v2.9.5 interface improvements, using a consistent official Material 3 icon set. The
release deliberately uses version 2.9.4 rather than reviving the deleted 2.9.5 release.

## Existing verified baseline

The current branch already contains and has manually verified:

- cache-first price lookup;
- API v2 public item lookup in batches of 10;
- 600 ms serialized network spacing;
- API v1 fallback;
- whole-batch schema fallback;
- mixed valid/malformed item handling;
- callback isolation;
- direct live API field-shape verification; and
- manual confirmation that real Quick Fill processes rows in batches of 10.

These behaviors must remain unchanged except where the bubble UI needs to display
progress or refresh state.

## v2.9.5 interface features to restore

### Circular bubble

Replace the current pill-shaped `.qp-chip` with the compact circular `.qp-bubble` from
the v2.9.5 refactor:

- 52×52 px fixed circular control;
- centered inline SVG icon;
- persistent position through `GM_setValue`;
- viewport clamping on restore and resize;
- Pointer Events dragging;
- keyboard repositioning with arrow keys;
- `role="button"`, `tabindex="0"`, and an accessible label.

### Route-aware behavior

Use the Torn hash route to determine bubble context:

- main/default route: info icon; tap opens the changelog;
- `#/add`: box/add icon; tap runs Quick Fill;
- `#/manage`: refresh icon; tap runs Update All;
- `#/personalize`: hide the bubble;
- route changes re-render the bubble without reinitializing the script.

### Add Items completion state

On the Add Items route, inspect the currently visible item rows:

- if every visible row has a non-empty positive price, use the pink completed state;
- otherwise use the normal accent state;
- re-evaluate after mutations and after Quick Fill completes;
- do not inspect or auto-scroll rows that Torn has not rendered.

### Gesture behavior

Use the v2.9.5 gesture rules:

- 350 ms long-press opens Settings;
- a short tap performs the route action;
- movement beyond 6 px cancels long-press and becomes a drag;
- a completed drag persists position and does not trigger tap;
- pointer cancellation clears timers and drag state;
- Enter/Space activates the route action without double-firing on keyup.

### Changelog modal

Add a styled “What’s new” modal opened by the main-route info bubble. It must:

- display the current version and release date;
- display the v2.9.4 release notes;
- close via the close button, scrim click, and Escape;
- use the existing dialog accessibility behavior;
- avoid injecting untrusted HTML from external data.

## Material 3 icon system

### Source and licensing

Download the selected icons from the official Material Design icon source:

- `https://fonts.google.com/icons`
- `https://github.com/google/material-design-icons`

Record the source and the Apache License 2.0 attribution in the repository. Keep a
copy of each downloaded SVG under `docs/assets/material-icons/` for provenance and
review. The userscript itself must remain self-contained, so selected SVG path data is
embedded in the script; there is no runtime icon-font or external icon request.

### Required mapping

| Semantic action | Material icon |
|---|---|
| Main/changelog | `info` |
| Add Items | `inventory_2` |
| Manage/update | `refresh` |
| Settings | `settings` |
| API key | `key` |
| Show key | `visibility` |
| Hide key | `visibility_off` |
| Add | `add` |
| Undo | `undo` |
| Success | `check_circle` |
| Error | `error` |
| Information | `info` |
| Warning | `warning` |
| Ranked-war weapon | `sports_martial_arts` |
| External link | `open_in_new` |
| Close | `close` |
| More options | `more_vert` |

All icons use `currentColor`, a 24×24 viewBox, and the existing type/weight conventions.
The icon mapping must be centralized and testable rather than scattered across templates.

## PDA initialization

Retain the current multi-stage initialization behavior and verify it remains intact:

1. immediate bazaar-root check;
2. DOMContentLoaded fallback;
3. MutationObserver fallback;
4. bounded polling fallback;
5. hard timeout cleanup.

Dialog opening must not unconditionally focus the API-key input, preserving the v2.9.5
PDA fix.

## Version and documentation

Update all release metadata to 2.9.4:

- userscript `@version`;
- runtime fallback `VERSION`;
- `package.json`;
- `package-lock.json`;
- README current version;
- changelog current version and v2.9.4 release entry;
- settings modal displayed version;
- `docs/BUILD.md` current version.

Document the circular bubble and Material 3 icon system as current behavior. Preserve
historical v2.9.5 notes only as historical context; do not claim that v2.9.5 is the
active release.

## Non-goals

- Do not change the API v2 batch size, cache format, cache lifetime, 600 ms spacing, or
  v1 fallback.
- Do not convert unrelated settings/UI code to a framework.
- Do not add a runtime dependency on Google Fonts or an icon CDN.
- Do not auto-scroll the bazaar.
- Do not modify quantity parsing or pricing calculations.
- Do not use a Full Access key or add key-verification API calls.
