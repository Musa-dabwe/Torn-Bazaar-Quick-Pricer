## Bugs Discovered & Fixed
Fixed in Tasks 1–2 and recorded in BUILD.md:
- **Bug: changelog gate on the base route** — the changelog opened from `bazaar.php#/`,
  where no bubble exists, and marked the version seen, so the user would never see the
  notes on the first real Add visit. Fixed by gating `maybeShowChangelog()` on the Add
  route. Status: FIXED.
- **Bug: drag branch un-hid the bubble** — the drag-hint render removed
  `qp-bubble-hidden`, revealing the bubble on unsupported routes. Fixed by checking the
  route before the drag branch. Status: FIXED.
- **Bug: stale post-fill clear state** — returning to Add kept offering to clear
  quantities the user may already have cleared. Fixed by resetting the bubble mode on
  `hashchange`. Status: FIXED.
- **Bug: clear-all could blank a checkbox** — a row checkbox the quantity-checkbox
  selector missed would be blanked, corrupting its checked state. Fixed with
  `input:not([type=checkbox])`. Status: FIXED.

## Key Decisions Made
- Base `bazaar.php#/`, Personalize, and unknown routes are unsupported and hide the
  bubble, rather than gaining a route-specific state: the base route has no batch action,
  and hiding is the only option that cannot un-hide itself mid-drag.
- The changelog is shown automatically only on the Add route, with dismissal persisted
  per version in GM storage; the settings info button is the manual override.
- The `clear` bubble state is in-memory only and resets on reload and on `hashchange`.
- Clear-all only touches currently loaded rows; the script still never scrolls.
- Documentation edits only: no source, pricing, quantity, API v2, or version-metadata
  changes in Task 3.
